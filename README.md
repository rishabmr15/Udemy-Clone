🎓 Udemy Clone – HTML & CSS 🎨

📌 Project Overview
This project is a static Udemy website clone developed as part of an assignment to practice and strengthen HTML and CSS skills. The main goal is to recreate the look and feel of the Udemy platform using only core frontend technologies without JavaScript or any frameworks.

🛠️ Technologies Used
🟧 HTML5 – Page structure and content  
🟦 CSS3 – Styling, layout, responsiveness, and hover effects  

✨ Features
✅ Responsive navigation bar  
✅ Course cards with images and details  
✅ Category sections similar to Udemy  
✅ Clean and modern UI design  
✅ CSS hover effects  
✅ Footer section  

📂 Project Structure
📁 udemy-clone  
📄 index.html  
🎨 style.css  
🖼️ images  
📘 README.md  

🚀 How to Run the Project
1️⃣ Clone the repository using git clone <repository-url>  
2️⃣ Open the project folder  
3️⃣ Open index.html in any browser  

📚 Learning Outcomes
📖 Improved understanding of HTML semantic elements  
🎯 Practical experience with CSS layouts and styling  
💡 Hands-on experience building a real-world UI clone  

⚠️ Notes
This project is created strictly for educational and assignment purposes. The UI design is inspired by Udemy and is not intended for commercial use.
